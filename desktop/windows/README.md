# iБюро — Windows desktop test installer

This is an **online-only** Electron shell around the currently deployed web application, `https://iburo127.online/app`. It does not package Next.js, store client documents locally by design, change payment/DB/scanner/production configuration, or make the unfinished staging application production-ready.

## Build on Windows

From `desktop/windows` run `npm ci` (if lockfile is present) or `npm install`, then `npm run check` and `npm run dist:win`. Output: `dist/iBuro-Setup-0.1.0-x64.exe`. NSIS offers a per-user installation and makes Start Menu and Desktop shortcuts. A branded ICO is generated by the included PowerShell script; no certificate is bundled.

## Security and limitations

Electron uses sandboxing, context isolation, disabled Node integration, normal TLS verification, blocks permissions, and only navigates within the `https://iburo127.online` origin; external HTTPS links are opened in the system browser. Browser sessions in Electron are separate from Chrome/Edge. Third-party OAuth and desktop download flows need real Windows QA before broader distribution. Internet access is required. No auto-update is configured.

**Unsigned test build only**: code signing, malware scanning, installation/uninstallation on clean Windows, authentication, document downloads, and final legal/security acceptance remain outstanding. Do not present this as a production-signed release or auto-publish it.
